# tokenizer

Deplying on `Sepolia`, the standard Etherum testnet, this project implements a simple ERC-20 token contract.

ETH blockchain has been choosen for history and wide adoption, and because of its robust smart contract capabilities. The ERC-20 standard is widely used for creating fungible tokens, making it an ideal choice for this project.

## Connect to Alchemy

Alchemy is a blockchain development platform that provides tools and infrastructure for building decentralized applications (dApps). 

Alchemy offers a suite of APIs and services that allow developers to interact with blockchain networks, manage smart contracts, and access real-time data. By connecting to Alchemy, developers can easily deploy and manage their ERC-20 token contract on the Sepolia testnet, ensuring a smooth development experience.

The most secure way to interact with the blockchain, in absolute, is to run our own node. However, this can be resource-intensive and time-consuming. Alchemy provides a convenient alternative by offering access to their infrastructure, allowing developers to focus on building their applications without worrying about the underlying blockchain connectivity.
